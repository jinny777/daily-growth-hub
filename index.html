🎙️ 다글로(Daglo) API 키 설정

    
다글로에서 발급한 API 키를 입력하세요. 한국어 음성 인식에 최적화되어 있습니다.

    
    
발급: daglo.ai → 회원가입 → API 키 발급

    

      
      
    

  







  

    
🤖 AI API 키 설정

    
Google Gemini API 키를 입력하세요. 무료로 발급 가능합니다.
키는 이 기기 브라우저에만 저장됩니다.

    
    
무료 발급: aistudio.google.com/app/apikey
Google 계정 로그인 → Create API Key

    

      
      
    

  







  

    

      
⚙️ 클라우드 동기화 설정

      
    

    

      💡 GitHub repo 권한 토큰으로 동작합니다.

      기존에 발급한 토큰을 그대로 사용하시면 됩니다.

      어떤 PC에서든 같은 데이터를 불러올 수 있습니다.
    

    

      

        
        
        
Settings → Developer settings → Personal access tokens → gist 권한만 필요

      

      

        
        
        
다른 PC에서 이 ID를 입력하면 동일한 데이터를 불러옵니다
